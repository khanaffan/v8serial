# Security policy

## Supported versions

Security fixes are provided for the latest `1.0.x` release.

| Version | Supported |
|---|:---:|
| 1.0.x | Yes |
| 0.1.x | No |
| Earlier versions | No |

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use
[GitHub private vulnerability reporting](https://github.com/khanaffan/v8serial/security/advisories/new)
and include:

- the affected API and version;
- a minimal reproduction or proof of concept;
- the expected security impact; and
- any suggested mitigation.

You should receive an initial response within seven days. Confirmed reports
will be investigated privately, with fixes and disclosure coordinated through
a GitHub security advisory.
